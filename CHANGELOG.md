# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-05-25

Initial public release.

### Added

- Automatic username skin lookup on join.
- Player skin commands for set, auto, clear, update, status, list, info, and random.
- Configurable fallback skins.
- Stable random fallback selection.
- Signed Mojang texture caching.
- Cache expiry for successful and failed lookups.
- Admin reload command.
- Compatibility permission nodes for existing server permission setups.
- GitHub Actions build workflow and release jar.
