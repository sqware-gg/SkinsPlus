# Screenshot Guide

Use this folder for GitHub, marketplace, and documentation screenshots.

## Recommended Captures

- `skin-set.png`: `/skin set <name>` success message.
- `skin-status.png`: `/skin status` output.
- `fallback-skin.png`: fallback skin behavior for a missing profile.
- `skin-list.png`: available fallback or cached skin list.

## Capture Notes

- Use a readable Minecraft GUI scale.
- Show the player model clearly when possible.
- Avoid showing private player data or full private configs.
- Keep images at least 1280px wide when possible.
